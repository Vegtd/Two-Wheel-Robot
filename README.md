A compact **two-wheel differential drive robot** designed for learning, prototyping, and experimentation in robotics, electronics, and embedded systems.

---

## 📌 Overview

This project is a **two-wheel robot chassis** powered by DC gear motors and mounted on a rigid base plate.  
It is suitable for line following, obstacle avoidance, autonomous navigation, and general robotics experiments.

---

## ⚙️ Features

- Differential drive (2-wheel configuration)
- Dual DC gear motors
- Solid and symmetric mechanical design
- Easy motor mounting system
- Expandable base for sensors and controllers
- Lightweight and durable structure

---

## 🧩 Mechanical Components

- **Chassis Plate**  
  Strong flat base with pre-drilled mounting holes for electronics and sensors.

- **DC Gear Motors**  
  Provide torque and stable speed control.

- **Wheels**  
  Rubber tires for better traction and smooth movement.

## 🔌 Electronics (Suggested)

- Microcontroller (Arduino / ESP32 / STM32)
- Motor Driver (L298N, L293D, TB6612FNG)
- Power Supply (Battery Pack 7.4V – 12V)
- Optional Sensors:
  - Ultrasonic sensor
  - IR line sensors
  - Encoder wheels
  - IMU

---

## 🚀 Applications

- Educational robotics projects
- Line follower robot
- Obstacle avoidance robot
- Autonomous navigation experiments

---

## 🛠️ Assembly Notes

- Ensure motors are aligned for straight movement
- Tighten wheel hubs securely
- Balance the battery placement for stability
- Leave space for future expansions
